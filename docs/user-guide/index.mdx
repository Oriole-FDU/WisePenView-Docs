# WisePen 用户手册

新版用户手册将围绕真实任务组织内容：先帮助你完成一件事，再解释相关能力、选择依据、产品规则和排错方法。

> 当前页面是新版手册的内容骨架。各章节将基于实际产品行为逐步补充并验证；原版手册已移出导航并保存在 `archive/user-guide-original`。

## 从这里开始

- **第一次使用 WisePen**：从“开始使用”了解核心概念并完成第一个任务。
- **想看完整工作方法**：进入“场景教程”，跟随材料、步骤和检查方法完成一项任务。
- **正在查某个功能**：直接进入 AI 对话、AI 能力、笔记与文档、云盘或小组章节。
- **遇到了问题**：前往“排错与参考”，按现象逐项检查。

## 内容编写标准

每篇正式指南应根据主题回答以下问题，而不是简单复述界面：

1. 这项能力适合什么场景，又不适合什么场景；
2. 使用前需要满足哪些条件；
3. 如何完成任务，以及成功后能看到什么结果；
4. 操作中有哪些重要选择，应该依据什么判断；
5. 哪些产品规则、权限或限制会影响结果；
6. 如何用真实示例验证结果；
7. 失败时如何定位问题并继续处理。
