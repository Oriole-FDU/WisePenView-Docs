# 组织协作空间与共享文件

> 本页是新版用户手册的内容模板。正式编写时将以实际产品行为和完整示例替换本提示。

## 本页要解决的问题

- 如何建立清晰的小组文件结构？
- 成员如何上传、查找和共同使用资源？
- 协作空间与个人云盘如何分工？

## 正式内容结构

### 适用场景

说明何时需要使用这项能力、预期产物是什么，以及不适用的情况。

### 开始前

列出账号状态、资源、权限、配置等前置条件。

### 完成任务

以一条完整路径说明操作、选择依据和每一步的可见结果；只在有助于定位或理解状态时使用截图。

### 完整示例

使用可复现的材料或任务展示输入、过程、结果与检查方法，不用泛化的宣传示例代替。

### 规则与限制

记录经验证的生效范围、权限关系、数据状态、不可逆操作及其他关键边界。

### 常见问题

按“现象 → 检查项 → 处理方法”组织排错内容，并链接到更详细的参考页面。
