# 注册、登录与身份认证

首次使用 WisePen 时，需要先注册账号。注册成功后，WisePen 会自动登录并引导你完成账号认证；你也可以暂时跳过认证，但大部分功能可能将无法使用。

## 注册前需要准备什么

注册账号需要自行设置用户名和密码。根据你准备采用的认证方式，还需要以下信息之一：

| 认证方式 | 需要准备 | 完成方式 |
| --- | --- | --- |
| 邮箱认证 | 一个可以正常接收邮件的完整邮箱地址 | 接收验证邮件，并按照邮件及页面提示完成验证 |
| 复旦 UIS 认证 | 复旦大学 UIS 账号与手机 | 发起认证后，按照页面返回的提示完成后续操作；系统可能要求扫码 |

如果暂时不方便认证，可以在注册后的认证页面选择「稍后再说」。

## 注册 WisePen 账号

1. 在登录页面点击「注册」。
2. 设置用户名。用户名必须满足以下条件：
   - 长度为 4～20 位；
   - 只能包含英文字母、数字或下划线；
   - 至少包含一个英文字母；
   - **不能直接使用学工号作为用户名**。
3. 设置密码。密码至少为 9 位，并且同时包含字母和数字。
4. 再次输入密码，确认两次输入一致。
5. 如有邀请码，可以填写「邀请码」。邀请码为 16 位字母或数字；没有邀请码可以留空。填写邀请码将使得邀请者与被邀请者均有机会获得一定数量的计算点或金币奖励。
6. 阅读并勾选「我已阅读并接受用户协议」。
7. 点击「注册」。

注册成功后，系统会使用新账号自动登录，并进入「完成账号认证」页面。如果自动登录失败，系统会返回登录页面，此时可以使用刚刚设置的用户名和密码手动登录。

:::tip 
注册时需要创建一个符合规则的用户名，**不能把学工号直接用作用户名**。完成 UIS 认证后，登录框支持填写「学工号/用户名」，**可以使用已关联的学工号或用户名登录**。
:::

## 完成账号认证

注册后的认证页面默认提供「复旦 UIS 验证」和「邮箱验证」两种方式。完成其中一种即可完成账号认证。

### 使用邮箱认证

1. 切换到「邮箱验证」。
2. 输入完整且可正常接收邮件的邮箱地址。
3. 点击「确认」，发送验证邮件。
4. 打开收到的验证邮件，并按照邮件中的链接和页面提示完成验证。
5. 页面显示验证成功后，可以前往账号设置查看认证结果。

发送验证邮件并不等于已经完成认证。必须继续处理验证邮件，直到页面显示「邮箱验证成功」。如果验证链接无效或已经过期，请返回账号认证入口重新发送验证邮件。

:::warning
合作高校不能使用邮箱认证。以复旦大学为例，复旦大学的学生应使用「复旦 UIS 验证」完成认证。
:::

### 使用合作高校认证

#### 复旦 UIS 认证

1. 保持或切换到「复旦 UIS 验证」。
2. 在「UIS 账号」中输入学工号或 UIS 账号。
3. 输入 UIS 密码。
4. 点击「确认」，发起 UIS 认证。
5. 等待系统检查认证状态。如果页面显示二维码或其他后续操作，请按照提示完成；出现二维码时，可以使用复旦大学 UIS 相关应用或微信等扫码。
6. 等待页面显示认证成功。

发起 UIS 认证后，页面会持续检查认证状态。不要把“已经提交账号和密码”当作认证完成，应以页面最终显示的结果为准。

:::warning
复旦 UIS 认证系统因开发方式限制可能存在不稳定的情况，如遇到超时或异常错误，请重试。**开发团队已与复旦大学信息办取得联系，即将通过OAuth方式接入复旦大学认证系统，届时可直接通过统一认证登录，敬请期待。**
:::

:::tip
**限时福利：复旦大学师生完成 UIS 认证将获得一定数量的计算点或金币奖励。**
:::

### 暂时跳过认证

点击「稍后再说」可以跳过本次认证并进入 WisePen，但部分功能要求身份认证后方可使用。账号管理页面也会持续显示认证提示，直到账号完成认证。

## 以后补充账号认证

如果注册时跳过了认证，可以随时从账号管理页面重新进入：

1. 打开页面左下方的用户菜单。
2. 选择「账号管理」。
3. 在页面顶部的账号验证提示中点击「去验证」。
4. 选择「复旦 UIS 验证」或「邮箱验证」，按照前文步骤完成认证。

认证成功后，与认证身份关联的账号资料可能不能再由用户自行修改。修改资料前，应先检查账号管理页面中字段当前是否可编辑。

## 登录 WisePen

已经拥有账号时，可以直接登录：

1. 在「学工号/用户名」中输入用户名；如果账号已经关联学工号，也可以输入学工号。
2. 输入 WisePen 账号密码。
3. 点击「登录」。

登录成功后，系统会进入原本准备访问的 WisePen 页面。登录即表示接受页面提供的用户协议。

### 忘记密码

登录页面提供「忘记密码」入口：

1. 点击「忘记密码」。
2. 输入注册时设置的用户名。
3. 点击「发送验证码」。
4. 如果账号具备可用于找回密码的邮箱，按照收到的邮件提示设置新密码。

新密码同样至少为 9 位，并且同时包含字母和数字。如果无法通过邮件完成找回，需要联系管理员协助重置密码。

:::warning
未认证的账号由于未设置邮箱，无法自行找回账号密码，需管理员协助重置密码。
:::

## 如何确认认证是否完成

进入「账号管理」后，可以根据页面状态判断：

- 页面仍显示“请通过邮箱验证或复旦 UIS 认证完成账号验证”的提示：账号尚未完成认证；
- 账号状态显示「已认证」，并显示邮箱认证、UIS 认证或校园身份认证等认证类型：账号已经完成认证；
- 刚完成认证但状态尚未更新：先重新打开账号管理页面，再检查状态。

## 常见问题

### 没有收到验证邮件

先确认邮箱地址填写正确，并检查垃圾邮件或广告邮件目录。等待一段时间后仍未收到，可以从「账号管理」→「去验证」重新发送。重复发送后仍无法收到时，再提交问题反馈，并说明使用的邮箱域名和发送时间；不要在反馈中提供邮箱密码或完整验证链接。

### 复旦大学 UIS 认证一直没有完成

确认页面是否显示二维码或其他待完成操作，并按照提示继续。认证尚在检查时不要反复提交。如果检查结束后显示失败，可以重新发起；持续失败时请联系管理员处理。

### 已经登录，为什么仍然要求认证

登录只验证 WisePen 账号和密码，不能替代邮箱或 UIS 身份认证。进入「账号管理」检查认证状态；如果仍显示认证提示，需要继续完成邮箱或 UIS 认证。
