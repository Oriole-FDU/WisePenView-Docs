# 上传、新建与组织文件

WisePen 既能保存从本地上传的文档，也能直接创建笔记、图表、Skill 和 Agent。个人资源和小组资源分别从不同页面进入；无论使用哪种入口，开始操作前都应先打开准备存放资源的具体目录。

如还不清楚个人云盘、小组空间和对话附件的区别，请先阅读[理解资源与存放位置](./locations-and-resources)。

## 进入云盘

### 进入个人云盘

1. 点击应用导航中的「我的云盘」，进入个人云盘页面。
2. 进入或保持在「文件」页签。
3. 使用页面内的目录树或文件列表进入目标文件夹；也可以停留在个人云盘根目录。

### 进入小组云盘

1. 点击应用导航中的「我的小组」。
2. 打开目标小组。
3. 进入或保持在「文件」页签。

**小组的根节点用于表示整个小组范围，不能直接放置资源，需要先进入或新建一个小组文件夹。**
能否创建文件夹、新建资源或从个人云盘添加资源，还取决于当前用户在该小组中的身份和权限。

### 使用「文件」快捷目录树

应用侧边栏的「文件」页签提供快捷目录树，可以在不进入完整云盘页面的情况下浏览和打开资源：

1. 打开应用侧边栏的「文件」页签。
2. 点击目录树根节点旁的「切换云盘」，选择个人云盘或目标小组。
3. 展开文件夹，找到需要使用的资源。
4. 点击资源将其打开。

## 新建文件夹和内容

在云盘的「文件」页面点击「新建」。菜单会根据当前位置、资源类型和当前权限显示可用操作，不同用户或目录看到的选项可能不同。

:::tip
**「新建」不会在后续步骤中再次要求选择目录**。资源会直接创建在当前目录中，因此应先确认所在位置。
:::

可用的新建操作包括：

| 菜单项 | 创建的内容 | 创建后发生什么 |
| --- | --- | --- |
| 新建文件夹 | 当前目录下的文件夹 | 文件夹出现在当前目录，可继续在其中组织内容 |
| 新建文档 | WisePen 笔记 | 创建后打开笔记编辑器 |
| 新建笔记 `即将支持` | 文档 (Word、PowerPoint、Excel) | 创建后打开 OnlyOffice 编辑器 |
| 新建图表 | DrawIO 图表 | 创建后打开图表编辑器 |
| 新建 Skill | 可复用的 Skill | 创建后打开 Skill 编辑器 |
| 新建 Agent | 可配置的 Agent | 创建后打开 Agent 编辑器 |

:::warning[开发中]
- 文档创建暂不可用，后续版本将开放此功能。
:::

### 新建文件夹

1. 进入准备创建下级目录的位置。
2. 点击「新建」→「新建文件夹」。
3. 输入文件夹名称并点击「创建」。

文件夹名称不能为空；同一目录下不能创建同名文件夹。**文件夹名称不能以 `.` 或 `/` 开头，这两个字符前缀由系统保留**。

### 新建笔记、文档或图表

1. 进入准备创建笔记、文档或图表的位置。
2. 点击「新建」→
    - 「新建笔记」后，WisePen 会创建一篇新笔记并直接打开编辑器。
    - 「新建文档」后需先指定文档类型；可以先填写文档名称；不填写时，系统使用「未命名Word文档」、「未命名PowerPoint文档」、「未命名Excel文档」。创建完成后会打开 OnlyOffice 编辑器。
    - 「新建图表」后，可以先填写图表名称；不填写时，系统使用「未命名图表」。创建完成后会打开图表编辑器。

:::tip
新建后先添加标题，再开始填写内容，这样可以减少之后在多个“未命名”资源之间辨认和移动的成本。
:::

### 新建 Skill 或 Agent

1. 进入准备创建笔记、文档或图表的位置。
2. 点击「新建」→「新建 Skill」或「新建Agent」后，需填写用于云盘列表展示的文件名，以及供模型使用的名称和描述。创建完成后会打开 Skill 或 Agent 编辑器。

资源在编辑器中完成配置、保存及必要的发布操作后方可被 AI 调用。详细配置将在[创建可复用的 AI 能力](../ai-capabilities/create-skill)说明。

## 上传和导入本地文件

在云盘的「文件」页面点击「新建」。菜单会根据当前位置、资源类型和当前权限显示可用操作，不同用户或目录看到的选项可能不同。

可用的导入操作包括：

| 菜单项 | 创建的内容 | 创建后发生什么 |
| --- | --- | --- |
| 导入笔记 | 由本地 Markdown 转换得到的笔记 | 创建笔记并打开，笔记标题默认取自文件名 |
| 导入图表 `即将支持` | 由本地 DarwIO 转换得到的图表 | 创建图表并打开 |
| 导入文档 | PDF 或 Office 文档资源 | 文件进入上传队列，处理完成后显示在当前目录 |
| 导入 Skill `即将支持` | 由本地 Skill 包解析得到的 SKill | 创建 Skill 并打开 |

:::warning[开发中]
- 图表导入、Skill包导入暂不可用，需先新建图表/Skill后再导入本地文件，后续版本将优化此流程。
- **「导入文档」目前显示为「从本地添加」**，此命名将在后续版本中变更。
:::

### 上传 PDF 和 Office 文档

1. 进入准备存放 PDF 和 Office 文档的位置。
2. 点击「新建」→「导入文档」。**「导入文档」暂命名为「从本地添加」。**
3. 在系统文件选择器中选择一个或多个支持的文档。

当前支持以下格式和大小：

| 文档类型 | 扩展名 |
| --- | --- |
| PDF | `.pdf` |
| Word | `.doc`、`.docx` |
| PowerPoint | `.ppt`、`.pptx` |
| Excel | `.xls`、`.xlsx` |

单个文件最大为 100 MB。文件选择器支持一次选择多个文档；不受支持的文件不会进入文档上传流程，页面会提示文件类型不受支持。

#### 查看上传与处理状态

上传并不是把字节传输完成就结束。文档还需要经过处理和资源注册，准备就绪后才会出现在目录中并可正常使用。
在页面提示文件已加入上传队列后，可切换到「上传队列」，根据以下状态判断进度：

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 本地计算中 | 浏览器正在为上传准备文件 | 保持当前页面可用，等待进入上传阶段 |
| 上传中 | 文件内容正在传输 | 避免关闭页面或中断网络 |
| 处理中、资源注册中 | 文件已上传，服务正在转换、解析或登记资源 | 继续等待，不要重复上传同一文件 |
| 准备就绪、处理完成 | 文档已经可以作为云盘资源使用 | 返回目标目录检查文件 |
| 上传失败、上传超时、资源注册超时或失败 | 当前任务未正常完成 | 查看错误信息，根据页面提供的操作重试或取消 |

完成项只会在队列中短暂显示，随后自动移除。

:::warning
部分文件上传后需要较长时间的转换和解析（特别是当文件非常大或页面数量很多时），当页面提示“处理仍在进行”时，应稍后查看上传队列而不是再次上传，重复提交会产生多个同名资源。
:::

### 从 Markdown 导入笔记

1. 进入准备存放笔记的位置。
2. 点击「新建」→「导入笔记」。
3. 选择一个扩展名为 `.md` 或 `.markdown` 的文件。
4. 检查标题、正文结构和复杂格式是否符合预期，再继续编辑或保存。

一次导入操作仅可选择一个 Markdown 文件。新笔记的默认标题来自文件名，并去掉 `.md` 或 `.markdown` 扩展名。Markdown 中的内容会交给笔记编辑器处理；导入完成后仍应检查表格、公式、嵌入内容和其他复杂结构，并非所有外部 Markdown 扩展都能原样呈现。

## 组织已有资源

### 规划文件夹结构

文件夹结构应帮助用户快速回答“这是什么”和“到哪里找”，而不是机械复制本地磁盘的所有层级。一个实用的结构通常包含：

1. **稳定的一级分类**：按照课程、项目或长期职责划分；
2. **任务或主题目录**：在一级分类下组织具体课题、章节或工作阶段；
3. **必要的归档目录**：存放已经结束但仍需保留的内容。

例如：

```text
研究方法课程
├── 课程资料
│   ├── 教师课件
│   └── 指定阅读
├── 小组项目
│   ├── 原始材料
│   ├── 阅读笔记
│   └── 最终成果
└── 归档
```

不建议为每一个文件建立单独文件夹，也不建议仅依赖“新建文件夹 1”“未命名笔记”等默认名称。层级过深会增加查找成本；同一批资源如果经常一起使用，应放在具有明确含义的共同目录中。

### 使用一致、可辨认的名称

名称应在离开正文内容后仍然能够辨认。可以包含：

- 主题或任务，例如“问卷设计”；
- 内容类型，例如“访谈提纲”“阅读笔记”；
- 必要的时间或版本，例如“2026 春”“方案 v2”。

不要在名称中放入密码、Token、身份证件号码等敏感信息。名称会出现在列表、搜索结果和协作空间中，其可见范围会大于正文内容。

### 重命名资源或文件夹

1. 在文件列表中找到目标条目。
2. 打开条目末尾的「更多操作」。
3. 选择「重命名」。
4. 输入新名称并确认。

对于已经添加到小组或被其他内容引用的资源，重命名前应考虑协作者是否仍能辨认新名称。

### 移动资源或文件夹

移动用于调整当前云盘范围内的组织位置。可以通过以下方式发起：

- 选择一个或多个条目后点击移动操作，再从目录树中选择目标文件夹；
- 将条目拖到目标文件夹；
- 打开资源后，通过页面提供的「移动到」入口选择目标目录。

移动文件夹会连同其下级内容一起调整位置。选择目标目录时，当前条目自身、无效的下级位置和部分系统目录不会作为可选目标。

小组云盘中的资源不能直接移动到小组根节点，需要选择具体文件夹。移动操作也不会用于在个人云盘和小组云盘之间复制内容；要让个人资源出现在小组中，应使用「从个人云盘添加」等入口。

移动完成后，返回目标目录确认资源是否出现。批量移动时，如果目标与原位置相同，页面会提示所选内容已经位于该处。

### 整理示例

假设你需要为一门“研究方法”课程整理材料：

1. 在个人云盘中新建“研究方法课程”文件夹。
2. 在其中建立“课程资料”“阅读笔记”和“小组项目”三个子文件夹。
3. 进入“课程资料”，通过「导入文档」一次选择课程 PDF 和教师课件。
4. 在上传队列中等待文档完成处理，然后回到“课程资料”检查文件。
5. 进入“阅读笔记”，使用「导入笔记」导入已有的 `.md` 阅读记录，检查格式后补充内容。
6. 新建内容时立即使用可辨认的标题；如果资源进入了错误目录，通过移动操作调整位置。
7. 需要与小组共享时，再将相关资源添加到小组的具体文件夹，并检查访问权限，而不是重新上传一份相同文档。

## 常见问题

### 为什么当前目录没有「新建」或某个菜单项？

如果正在使用「我的云盘」，先确认当前位于「文件」页签，而不是上传队列、收藏或回收站。
如果正在使用小组文件页面，则应检查是否已经进入可以保存资源的具体文件夹。
随后确认当前账号是否具有创建或挂载权限；界面会隐藏当前环境中不可用的操作。

### 为什么不能直接把文件上传到小组云盘根目录？

小组根节点用于选择小组范围，不是实际文件夹。请先新建或进入一个小组文件夹，再执行上传或新建操作。

:::warning
这一问题将在后续开发中进行优化。
:::

### 为什么文件已经上传，却还不能打开？

文件传输完成后仍可能处于转换、解析或资源注册阶段。前往「上传队列」检查状态；只有准备就绪后，文档才能作为正常资源使用。

### 为什么上传队列中的完成项消失了？

完成项会自动从队列中移除。返回上传时选择的目标目录查看资源。如果目录中仍没有文件，刷新后再次检查，并确认最初是否选择了其他文件夹。

### 为什么选择了多个文件，最后只上传了一部分？

上传流程会过滤不受支持的文件。检查未上传文件的扩展名和大小：当前文档上传只支持 PDF、Word、PowerPoint 和 Excel，单文件不能超过 100 MB。失败项还应结合上传队列中的错误信息处理。

### 为什么导入 Markdown 后格式发生变化？

导入功能把 Markdown 内容转换为 WisePen 笔记，不是将外部编辑器完整嵌入。不同 Markdown 工具的扩展语法并不完全一致；请在笔记编辑器中检查复杂表格、公式、嵌入内容和特殊样式。
