# 理解资源与存放位置

WisePen 将笔记、文档、图表和 AI 能力统一作为**资源**管理。你可以在个人云盘中整理自己的资源，也可以把资源添加到小组云盘供成员使用；在 AI 对话中，还可以临时上传附件或引用云盘中的文档。

## 什么是资源

“资源”是 WisePen 中可以被保存、打开、组织和授权的内容对象。当前常见资源包括：

| 资源类型 | 产生方式 | 通常使用的工作区 |
| --- | --- | --- |
| 笔记 | 新建笔记，或导入 Markdown | 笔记编辑器 |
| PDF | 从本地上传 | 文档预览 |
| 文档 (Word、PowerPoint、Excel) | 新建文档，或从本地上传文档 | 文档预览或 Office 工作区 |
| 图表 | 新建图表，或导入 DrawIO | DrawIO 图表编辑器 |
| Skill | 新建 Skill，或导入 Skill 包 | Skill 编辑器 |
| Agent | 新建 Agent | Agent 编辑器 |
| App `实验性功能` | 由 AI 构建 | WisePen App 基座 |
| 音频、视频 `即将上线` | 从本地上传 | 音视频播放器 |

文件夹用于组织资源，本身不是一种资源。收藏不会创建新的资源，只为现有资源增加一个便于再次查找的入口。

:::info
笔记、文档、图表、Skill 和 Agent 等内容可以直接在 WisePen 中创建，并不要求先有一个本地文件。
反过来，本地文件只有在完成上传和资源注册后，才会成为云盘中可持续管理的资源。
:::

:::warning[开发中]
- 文档目前暂不支持直接在 WisePen 中创建，后续版本将开放此功能。
- 图表目前暂不支持直接在 WisePen 中上传，需先新建图表后再导入本地文件，后续版本将优化此流程。
- Skill 包暂不支持直接在 WisePen 中上传，需先新建 Skill 后再导入本地文件，后续版本将优化此流程。
- App `实验性功能` 暂不允许从本地上传，后续版本或将开放此功能。
- **音频、视频即将上线，当前版本暂不支持此类型资源。**
:::

## 三种常见的资源位置

### 个人云盘

个人云盘是整理个人资源的主要入口。你可以使用多级文件夹组织资源，并在当前目录中新建或者上传支持的资源。

适合放在个人云盘的内容包括：

- 尚在整理、不准备交给小组共同使用的材料；
- 自己创建和维护的笔记、Skill 或 Agent；
- 准备稍后添加到课程或协作小组的资源；
- 需要长期保存、继续编辑和反复引用的文档。

### 小组云盘

小组云盘用于组织课程小组或协作小组中的共享内容。你只能进入自己有权访问的小组；进入后，可见内容和可执行操作还会受到小组身份、文件夹策略和资源权限影响。

将个人云盘中的资源添加到小组文件夹时，WisePen 会在该小组中建立资源的挂载关系。可以把它理解为：

- 小组中增加了一个访问该资源的位置；
- 资源内容没有因此复制成两份；
- 同一个资源可以出现在不同的组织位置；
- 在一个位置修改资源内容，打开的仍是同一个资源，而不是各自独立的副本。

因此，“从小组移除”和“删除资源本体”是两种不同操作。前者解除资源与小组位置的关系，后者会影响指向该资源的其他位置。

:::warning[位置与权限是两套规则]
资源出现在某个小组文件夹中，只说明它被组织到了该位置，不等于每位小组成员都自动获得相关权限。WisePen 分别控制：

1. 谁可以把资源挂载到文件夹；
2. 文件夹中的资源默认授予谁哪些访问能力；
3. 资源自身是否存在单独的权限设置。

需要协作时，应同时检查资源所在位置和实际权限，而不能只看它是否出现在小组中。
:::

### AI 对话中的材料

AI 对话提供两种添加材料的方式，但它们不会改变云盘中的文件。

| 添加方式 | 实际行为 | 是否自动进入个人云盘 |
| --- | --- | --- |
| 从本地选取 | 将本地文件上传为当前会话可使用的附件 | 否，除非要求 AI 上传至云盘 |
| 从云盘选取 | 在对话中引用一个已有云盘文档 | 资源仍在原位置 |

从本地选取适合临时分析材料。如果文件之后还需要整理、共享或在其他任务中反复使用，应另行上传到个人云盘。
从云盘选取则适合引用已经保存和整理好的文档。

在输入框中移除附件或文档引用，只会把它从当前待发送的对话上下文中移除，不会删除本地原文件或云盘资源。

## 文件夹、挂载与资源本体

传统文件系统常让人以为“一个文件只能存在于一个文件夹”。WisePen 的资源组织方式更灵活，需要区分三个概念：

- **资源本体**：实际的笔记、文档、图表、Skill、Agent等资源；
- **文件夹**：用于分类和浏览资源的组织结构；
- **挂载或链接**：让同一个资源出现在某个文件夹或小组中的关系。

例如，一份名为“调研方法综述”的 PDF 可以作为资源保存在你的个人云盘中，同时被添加到“研究小组”的“文献”文件夹。小组成员打开的是同一份资源，而不是系统自动制作的副本。

这也解释了不同删除提示的含义：

| 页面提示 | 影响 |
| --- | --- |
| 删除链接 | 仅删除当前文件夹中的链接，资源本体不受影响 |
| 从小组移除 | 解除当前小组中的挂载；不会直接删除资源本体 |
| 移入回收站 | 删除资源本体的当前有效入口，其链接会同步失效；之后可以从回收站恢复 |
| 永久删除 | 删除资源本体且不可撤销 |

## 如何选择存放位置

可以从“是否需要长期保存”和“谁需要使用”两个问题开始判断：

| 你的目标 | 建议方式 | 原因 |
| --- | --- | --- |
| 临时让 AI 阅读一次本地材料 | 在对话中从本地选取 | 无需先整理进云盘，也不会自动沉淀为云盘资源 |
| 需要经常查找、编辑或再次引用 | 保存到个人云盘 | 可以持续管理、移动和从云盘引用 |
| 先自己整理，成熟后再给小组使用 | 先放个人云盘，再添加到小组 | 个人整理和小组展示可以分阶段进行 |
| 供课程或协作小组成员共同使用 | 添加到合适的小组文件夹 | 小组成员能从共同的组织位置找到资源 |
| 只是想以后更快找到现有资源 | 收藏资源 | 收藏不改变资源位置，也不复制内容 |

### 一个完整例子

假设你准备和研究小组分析一份课程论文：

1. **需要长期保留原文**：先将 PDF 上传到个人云盘的“课程论文”文件夹，等待上传队列显示资源准备就绪。
2. **需要小组成员共同访问**：从个人云盘将该 PDF 添加到研究小组的“共享文献”文件夹，并检查成员是否具有所需的查看或其他权限。
3. **需要 AI 辅助分析**：在 AI 对话中选择「从云盘选取」，引用这份 PDF。
4. **需要保存分析成果**：新建笔记整理结论。根据使用范围，将笔记保留在个人云盘，或再添加到小组空间。
5. **不再需要小组入口**：从小组中移除挂载即可；如果原文仍需保留，不要永久删除资源本体。

这条路径中只有一份 PDF 资源。个人云盘和小组文件夹分别承担长期管理与协作发现的作用。

## 常见问题

### 把资源添加到小组后，个人云盘中的原资源为什么还在？

这是正常现象。添加到小组通常建立的是挂载关系，并非把资源从个人云盘搬走，也不是制作一个独立副本。

### 同一份资源出现在两个文件夹，是不是产生了两份内容？

不一定。WisePen 支持通过链接或挂载让同一个资源出现在多个位置。可以打开资源核对内容，不要仅凭列表位置判断资源是否被复制。

### 为什么小组成员能看到资源，却不能编辑？

资源的位置和权限相互关联但并不等同。成员可能只有查看权限，或者文件夹默认权限、资源单独权限限制了编辑操作。应检查该成员的小组身份以及文件夹和资源的权限设置。

### 为什么把文件添加到对话后，在个人云盘里找不到？

如果使用的是「从本地选取」，文件只作为会话附件上传，不会自动保存到个人云盘。需要长期管理时，请另外从云盘页面上传。如果使用的是「从云盘选取」，原资源仍位于选择时所在的云盘目录。

### 从小组移除资源，会不会删除个人云盘中的原件？

“从小组移除”处理的是该资源在小组中的挂载关系，不会直接删除资源本体。操作前仍应阅读确认窗口：如果页面提示“移入回收站”或“永久删除”，处理的就不是单纯的小组挂载。

### 移动、收藏和添加到小组有什么区别？

- **移动**改变资源或文件夹的组织位置；
- **收藏**增加个人快捷入口，不改变原位置；
- **添加到小组**为小组建立资源入口，并受小组及资源权限控制。
