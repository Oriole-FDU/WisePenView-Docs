# 站点地图

文档站按读者任务组织。当前只保留基础页面，后续有实际内容时再新增目录。

## 栏目划分

| 位置 | 适合放什么 | 典型读者 |
| --- | --- | --- |
| `docs/getting-started` | 站点说明、本地预览、目录约定 | 新成员、内容维护者 |
| `docs/contributing` | 写作风格、页面模板、命名规则 | 所有贡献者 |
| `docs/operations` | 部署、环境、发布注意事项 | 开发、运维、负责人 |

## 页面命名

- 路径使用英文小写与短横线，例如 `product/resource-viewer`。
- 标题使用中文，尽量和产品里的模块名称一致。
- 一个页面只解决一个主题；主题变大时拆分为子页面。

## 内容成熟度

页面可以先用占位结构合入，再逐步补齐。建议按这三个阶段维护：

1. `草稿`：有标题、读者、范围和待补清单。
2. `可读`：有主要流程、截图或示例，能支持独立阅读。
3. `稳定`：经过产品、设计或开发校对，可作为协作依据。
