# 内容写作规范

WisePen 文档应该像产品本身一样清楚、克制、可操作。先说明读者要完成的任务，再给步骤、边界和例外。

## 口吻

- 使用中文为主，必要的产品名、接口名、文件名保留英文。
- 少写宣传语，多写具体行为和限制。
- 遇到暂未确定的内容，明确标注“待补”或“待确认”。

## 结构

每页至少包含：

- 页面用途。
- 适用读者。
- 主体说明。
- 相关链接或下一步。

## 链接

- 站内文档使用相对链接。
- 文件路径使用代码样式，例如 `src/pages/index.tsx`。
- 外部链接需要确认目标长期稳定。

## 图片与截图

后续补截图时，建议放在当前文档同级的 `img` 目录，文件名使用英文小写短横线。
