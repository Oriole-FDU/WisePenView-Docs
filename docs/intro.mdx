# WisePen 文档总览

这里是 WisePenView 与 WisePenView-Portal 的统一文档入口。当前只保留最基本的站点结构，后续按实际需要新增产品说明、开发说明、截图和接口资料。

## 这个文档站解决什么

- 给文档内容一个稳定入口。
- 给后续页面一个清楚的归档规则。
- 保留 WisePen 的基础视觉风格，但不把文档站做成产品展示页。

## 推荐阅读路径

1. 先看 [站点地图](./getting-started/site-map)，确认内容应该放在哪个栏目。
2. 再看 [本地开发](./getting-started/local-development)，启动文档站并预览改动。
3. 写新页面前，看 [内容写作规范](./contributing/content-style)。
4. 发布前，看 [部署说明](./operations/deployment)。

## 建设原则

文档站先追求朴素、稳定、可继续扩展。页面不必一次写满，但每个新增页面都应该说明读者是谁、覆盖什么，以及下一步应该看哪里。
