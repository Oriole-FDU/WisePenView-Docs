# 部署说明

文档站是静态站点。生产部署只需要构建并发布 `build` 目录。

## 构建命令

```bash
pnpm build
```

## 部署前确认

- `docusaurus.config.ts` 中的 `url` 和 `baseUrl` 与目标域名一致。
- 新增页面已经加入 `sidebars.ts`。
- 首页入口链接能跳到有效页面。
- 没有遗留 Docusaurus 模板文案出现在可见导航中。
